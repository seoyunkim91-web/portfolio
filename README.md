# 김서윤 · 광고 플랫폼 PM 포트폴리오

지그재그 광고플랫폼 PO 지원을 위해 작성한 정적 웹 포트폴리오입니다. `index.html` 하나로 동작하며 별도 빌드나 외부 라이브러리가 필요하지 않습니다.

## GitHub Pages 게시

저장소의 **Settings → Pages → Build and deployment**에서 **Deploy from a branch**, `main`, `/ (root)`를 선택합니다. 게시 후 표시되는 Pages 주소를 지원서의 **기타 링크**에 입력합니다.

프로젝트의 도식은 실제 운영 화면이나 수치가 아닌 설명용 재구성입니다.
